# Сальдо

Учебное мобильное приложение на Flutter для iOS и Android. Каркас включает импорт тестового брокерского отчёта, предпросмотр и просмотр подтверждённых сделок.

## Запуск с чистого клона

### 1. API и база данных

Установите Docker с Compose и из корня репозитория выполните:

```sh
docker compose up --build -d --wait
curl -fsS http://127.0.0.1:18080/health
```

Если Compose установлен отдельной командой, используйте `docker-compose` вместо `docker compose`. Go на хосте не требуется. Данные PostgreSQL остаются в томе между запусками. При занятом порте задайте `SALDO_API_PORT=18082` перед командой Compose и используйте этот же порт в адресах ниже.

Если переходите со старого локального запуска, остановите прежний `go run .` на порту 18080. Запускайте Compose из той же папки, чтобы сохранить существующий том.

### 2. Мобильное приложение

Установите **Flutter 3.47.9**, Python 3 и инструменты выбранной платформы. Для iOS нужны macOS, Xcode с установленным iOS Simulator Runtime и CocoaPods, если его запрашивает Flutter. Для Android нужны Android SDK и запущенный Android Emulator. Проверьте окружение через `flutter doctor`.

```sh
./scripts/bootstrap-mobile.sh
cd mobile
flutter devices
flutter run
```

При нескольких устройствах добавьте `-d ID_УСТРОЙСТВА`. Скрипт генерирует платформенные папки и устанавливает зависимости из `pubspec.lock`. По умолчанию клиент обращается к `http://127.0.0.1:18080` в iOS Simulator и к `http://10.0.2.2:18080` в стандартном Android Emulator. Для другого порта передайте полный адрес через `--dart-define=API_URL=...`. Конфигурация Compose рассчитана на запуск клиента в симуляторе или эмуляторе.

### 3. Проверка импорта

Откройте `http://127.0.0.1:18080/sample.csv` в Safari симулятора или `http://10.0.2.2:18080/sample.csv` в браузере Android Emulator. Скачайте файл и откройте в «Сальдо» **Портфель → + → Выбрать CSV**. Подтвердите импорт и откройте список подтверждённых сделок. В нём должны появиться `trade-1` и `trade-2`.

Из корня репозитория можно проверить тот же сценарий на уровне API:

```sh
python3 scripts/check-import.py
```

### 4. Проверка ручной операции

В приложении откройте **Операции → Добавить**, выберите счёт и категорию, введите сумму и нажмите галочку. Запись появится в разделе «Добавленные операции». Закройте и снова запустите приложение, чтобы проверить загрузку записи из PostgreSQL. Демо-балансы и графики из макета пока не пересчитываются по этим записям.

## Архитектура и выбор технологий

| Компонент | Решение |
| --- | --- |
| Мобильный клиент | Flutter и Dart дают общую кодовую базу для iOS и Android. |
| API | Один Go-сервис разбирает CSV и обрабатывает предпросмотр и подтверждение. Серверный разбор даёт одинаковое поведение на обеих платформах. |
| База данных | PostgreSQL хранит разобранные сделки и состояние импорта. Хеш файла защищает от повторной записи идентичного отчёта. |
| Сборка | Compose запускает API и БД. GitHub Actions проверяет этот же Compose-сценарий, собирает Android APK и iOS-приложение для симулятора. |

Используйте синтетические данные. API каркаса предназначен для локального запуска и использует общую таблицу импортов без авторизации. Балансы и позиции на экранах демонстрационные. Реальные форматы брокеров, расчёт позиций, календарь, OAuth и офлайн-хранение входят в дальнейшую разработку MVP.
